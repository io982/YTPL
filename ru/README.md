# YTPL — конвертер YouTube в плейлист

Скрипт на Python для скачивания видео с YouTube и нарезки аудио на сегменты по временным меткам из описания, страницы видео или путём анализа пауз.

## Возможности

- Скачивание аудио с YouTube через yt-dlp
- Автоматическое извлечение временных меток из описания и HTML-кода страницы
- Поддержка форматов: `&t=145s`, `?t=145s`, `=1102s` в URL, `MM:SS`, `HH:MM:SS`
- Ручной ввод меток
- **Автоматическое определение пауз между треками (silence detection), если метки не найдены**
- Нарезка аудио на MP3-сегменты через ffmpeg
- Безопасные имена файлов (санитизация)
- Улучшенная обработка ошибок и логирование
- Автоматическая очистка временных файлов
- Валидация меток (пропуск некорректных и перекрывающихся)

## Требования

- Python 3.8+
- yt-dlp
- requests
- beautifulsoup4
- imageio-ffmpeg (включает ffmpeg)

## Установка

1. Установите зависимости Python:
   ```bash
   pip install yt-dlp requests beautifulsoup4 imageio-ffmpeg
   ```

2. Убедитесь, что ffmpeg доступен (поставляется с imageio-ffmpeg)

## Использование

Запустите скрипт:

```bash
python YTPL.py
```

Или дважды щёлкните `YTPL.bat` (Windows).

Введите URL видео YouTube, когда будет предложено.

При желании введите ручные метки через запятую в секундах (например, `145,325`) или оставьте поле пустым для автоматического извлечения.

Скрипт выполнит:
- Загрузку информации о видео
- Извлечение временных меток из описания и страницы
- **Если метки не найдены — анализ пауз (silence detection) для поиска границ между треками**
- Скачивание аудио и конвертацию в MP3
- Нарезку на сегменты по меткам (или по обнаруженным паузам)
- Сохранение MP3-файлов с санитизированными именами

## Результат

Файлы сохраняются в папку, названную по имени видео.

Каждый сегмент: `{название_видео}/{название_видео}_{номер:04d}.mp3`

Например: `My_Video/My_Video_0001.mp3`, `My_Video/My_Video_0002.mp3`

## Поддерживаемые форматы меток

- URL-параметры: `&t=145s`, `?t=2m25s`
- Текстовые таймкоды: `1:30`, `1:30:25`
- Нестандартные URL: `https://youtu.be/...=1102s`
- **Резервный анализ пауз: если метки не найдены, ffmpeg-фильтр `silencedetect` сканирует амплитуду аудио и находит промежутки тишины между треками (настраивается через `noise_tol` и `min_silence_dur`)**

## Обработка ошибок

- Если в описании нет меток — анализ HTML-кода страницы
- **Если меток нет нигде — автоматический анализ пауз (silence detection)**
- Если меток всё равно нет — запрос ручного ввода
- Корректная обработка некорректных URL и отсутствующих зависимостей
- Валидация меток, пропуск некорректных и перекрывающихся
- Автоматическая очистка временных файлов при выходе или ошибке
- Проверка доступности ffmpeg перед началом обработки
- Подробное логирование для диагностики

## Улучшения в последней версии

- **Детектор пауз через ffmpeg `silencedetect` — автоматическая нарезка миксов/альбомов без готовых меток**
- Временные файлы в изолированных временных папках (без мусора в рабочей директории)
- Улучшенные сообщения об ошибках с временными метками через модуль logging
- Валидация временных меток перед обработкой
- Корректная обработка Ctrl+C
- Возврат списка созданных сегментов для возможного программного использования
